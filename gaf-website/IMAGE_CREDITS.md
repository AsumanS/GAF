# Image credits

This file tracks rights information for images used on the Golden Archive Foundation website.

Do not invent creators, institutions, dates, licenses, or source URLs. Leave entries blank until verified.

## Image directories

- `public/images/foundation/` — foundation identity and social preview assets
- `public/images/projects/lost-stories/` — Lost Stories project imagery
- `public/images/projects/worlds/` — Worlds Imagined project imagery

## Record template for future images

When adding an image, also add a matching object in `src/data/images.ts` using:

- `fileName`
- `title`
- `creator`
- `date`
- `sourceInstitution`
- `sourceUrl`
- `rightsStatement`
- `license`
- `requiredCreditLine`
- `altText`
- `caption`

See `CONTENT_ASSET_CHECKLIST.md` and `DESIGN_SYSTEM.md`.
